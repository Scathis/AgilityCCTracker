# AgilityCCTracker

Wildy Agility FC Tracker: a RuneLite plugin, a self-hosted API and a web dashboard. It tracks attendance, laps, loadout compliance and DD calls for a Wilderness Agility friends chat.

The build specification is in [`docs/BUILD_PLAN.md`](docs/BUILD_PLAN.md). To build it on the host server, run Claude Code in this repo and ask it to execute the plan from Phase 0.
